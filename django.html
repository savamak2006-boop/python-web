Django

Django - это высокоуровневый full-stack фреймворк на Python, который появился в 2005 году и с тех пор стал одним из самых популярных инструментов для создания веб-приложений. Его девиз - «батарейки в комплекте»: всё необходимое уже встроено, от ORM до админ-панели.

Django выбирают, когда нужен надёжный, масштабируемый и безопасный проект «под ключ» - без сборки десятка сторонних библиотек.

История

Django был создан в редакции Lawrence Journal-World для внутренних нужд - нужно было быстро выпускать новостные сайты. В 2005 году фреймворк открыли под лицензией BSD, и он быстро набрал популярность.

Сегодня на Django работают Instagram, Pinterest, Disqus, Mozilla и тысячи других проектов по всему миру.

Ключевые особенности

  • ORM - работа с базой данных через Python-классы, без SQL.
  • Админ-панель - автоматически генерируется из моделей.
  • Шаблонизатор - собственный язык шаблонов с наследованием.
  • Аутентификация - встроенная система пользователей и прав.
  • Маршрутизация - гибкая система URL-ов и представлений.
  • Безопасность - защита от CSRF, XSS, SQL-инъекций из коробки.

Плюсы и минусы

Плюсы

  • Много готовых инструментов
  • Большое сообщество
  • Хорошая документация
  • Подходит для крупных проектов

Минусы

  • Много «магии» для новичков
  • Избыточен для маленьких проектов
  • Монолитная структура
