# Python фреймворки для Web-разработки

Учебный проект о Python-фреймворках для веб-разработки: Django, Flask и FastAPI.

## Ссылки

- [Сайт на GitHub Pages](https://savamak2006-boob.github.io/python-web/)
- [Репозиторий на GitHub](https://github.com/savamak2006-boob/python-web)

## О проекте

Сайт рассказывает о том, какие бывают Python-фреймворки для веб-разработки, чем они отличаются, где применяются и когда что использовать. Материал разбит на отдельные страницы, чтобы можно было изучать тему последовательно — от общих принципов к конкретным инструментам.

## Страницы

- **Главная** — обзор темы, сравнение фреймворков
- **Django** — обзор full-stack фреймворка
  - История создания
  - Ключевые особенности
  - Пример кода
  - Плюсы и минусы
- **Flask** — обзор микрофреймворка
  - История создания
  - Ключевые особенности
  - Пример кода
  - Плюсы и минусы
- **FastAPI** — обзор асинхронного фреймворка
  - История создания
  - Ключевые особенности
  - Пример кода
  - Плюсы и минусы
- **Сравнение** — таблица характеристик трёх фреймворков
- **Видео** — подборка видео-уроков с RuTube
- **О сайте** — информация об авторе и проекте

## Технологии

- **HTML5** — семантическая разметка
- **Tailwind CSS 4** — утилитарный CSS-фреймворк
- **JavaScript** — бургер-меню для мобильных устройств
- **Node.js + npm** — сборка Tailwind CSS
- **Git + GitHub** — система контроля версий
- **GitHub Pages** — хостинг

## Как пользоваться сайтом

Перейдите по ссылке или скачайте репозиторий, распакуйте архив и откройте `index.html` в браузере. Все страницы связаны между собой через навигацию.
